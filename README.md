# أتعلم بطريقتي

تطبيق تعليمي بالعربية ليمان (الصف العاشر–الحادي عشر): دروس بخطوات ملوّنة، صور توضيحية تفاعلية، امتحانات تجريبية، مراجعة متباعدة، ومتابعة التقدّم.

- `/` – تطبيق الطالب
- `/parent` – صفحة متابعة للوالدين (بالعبرية)
- `/api/state` – حفظ التقدّم (Vercel Blob، خاص)
- `/api/ask` – الأستاذ سامر (Claude API)
- `/api/summary?code=…` – ملخّص يومي لتطبيقات أخرى (Hero Family)

## متغيّرات البيئة في Vercel
- `FAMILY_CODE` – رمز العائلة للدخول
- `ANTHROPIC_API_KEY` – مفتاح Claude API للمعلّم الذكي
- `BLOB_READ_WRITE_TOKEN` – يُضاف تلقائيًا عند ربط مخزن Blob
